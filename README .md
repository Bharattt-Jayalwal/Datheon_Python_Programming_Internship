# Hangman – Word Guessing Game 🎮

## 📌 Project Overview

Hangman is an interactive, terminal-based word guessing game developed using Python. The computer randomly selects a hidden English word, and the player must guess it letter by letter within six incorrect attempts.

The game provides an engaging console experience with ASCII gallows graphics, real-time letter tracking, input validation, and replay functionality.

## ✨ Key Features

- Random English word selection
- Interactive letter-by-letter guessing
- Dynamic ASCII Hangman graphics
- Maximum of six incorrect attempts
- Previously guessed letter tracking
- Duplicate guess prevention
- Input validation for invalid entries
- Clear victory and defeat messages
- Option to replay the game

## 🚀 How to Run the Project

**Step 1:** Install Python 3.

**Step 2:** Clone this repository:

```bash
git clone https://github.com/Bharattt-Jayalwal/HANGMAN-WORD-GUESSING-GAME.git
```

**Step 3:** Open the project folder in VS Code.

**Step 4:** Run the following command in the terminal:

```bash
python hangman.py
```

**Step 5:** Start guessing letters and enjoy the game!
