# Hangman – Word Guessing Game

## Project Overview
Hangman is a terminal-based word guessing game developed using Python. The player must guess a randomly selected hidden word within six incorrect attempts.

## Features
- Random English word selection
- Interactive letter guessing
- ASCII Hangman graphics
- Six incorrect attempts
- Previously guessed letter tracking
- Duplicate guess prevention
- Input validation
- Victory and defeat screens
- Replay functionality

## Technologies Used
- Python 3
- Random module
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute:

```bash
python hangman.py
```
